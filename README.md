# 可靠性综合管理系统

单文件离线工具，直接双击 `test.html` 用 Edge / Chrome 打开即可，无需服务器、无外部依赖。
数据默认保存在浏览器 `localStorage`，可通过「数据管理」导出/导入 `data.json`。

## V2.5 变更

### 出货与计划解耦

之前「计划板数」和「已出板数」是绑在一起的：已出多少，就必须把计划改到多少才能再出一次货。
现在出货只做两件事——**按 BOM 扣库存、记一条出货记录**，和计划板数完全无关：

- 计划 100、先出 100、再出 100 都可以，不需要改计划（`shipped` 会累计到 200）；
- 每次出货写入 `boards.<底板/HAST板/顶板>.shipments`：`{id, at, qty, note}`；
- BOM 区新增「记录 N」按钮，可查看历史出货、撤销最近一次（库存自动加回，并写一条反向流水）；
- 计划板数只用于「需求核算」，输入框上已标注；计划小于已出不再报错，只把数字标红。

### 需求核算只看本次计划

- 需求 = **计划板数 × BOM 单板用量**，再和当前库存比较，**不再扣减历史出货**；
- 出完 100 块后，计划照旧写 100，汇总表仍然显示 200 的需求，不需要把上次的数量加上去；
- 出货记录只用于追溯，不参与任何计算。

### 台账拖拽排序与分组折叠

- 「拖拽排序」进入平铺模式，拖动行即可调整顺序，退出后按新顺序展示，顺序会落盘；
- 「电容 / 电阻 / 保险丝 / 螺丝 / 散热片」分组行点击（或键盘 Enter / 空格）可折叠展开；
- 折叠状态存在 `localStorage` 的独立键里，不写进 `data.json`，不影响数据格式。

## 数据兼容

`data.json` 结构未破坏性变更，**V2.4 导出的备份可直接导入 V2.5**：

- 读：`boards.*.shipments` 缺失时自动补 `[]`，脏数据（非数组 / 混入 null）会被过滤；
- 写：在原有 `{qty, bom, shipped}` 基础上追加 `shipments`，旧版程序读到会忽略该字段；
- 导出头部的 `version` 变为 `2.5`，`material` / `test` 两部分结构与 V2.4 一致。

## 浏览器要求

- `DecompressionStream`（Excel 导入）与 CSS `:has()`：Chrome / Edge 105+；
- 通过 `file://` 打开时，浏览器的「自动加载 data.json」会被安全策略拦掉，请用「数据管理 → 选择 data.json」或直接拖入页面。
