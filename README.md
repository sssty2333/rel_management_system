# 可靠性综合管理系统

单文件离线工具，直接双击 `test.html` 用 Edge / Chrome 打开即可，无需服务器、无外部依赖。
数据默认保存在浏览器 `localStorage`，可通过「数据管理」导出/导入 `data.json`。

## V2.5 变更

### 出货与计划解耦

之前「计划板数」和「已出板数」是绑在一起的：已出多少，就必须把计划改到多少才能再出一次货。
现在出货只做两件事——**按 BOM 扣库存、记一条出货记录**，和计划板数完全无关：

- 计划 100、先出 100、再出 100 都可以，不需要改计划（`shipped` 会累计到 200）；
- 每次出货写入 `boards.<底板/HAST板/顶板>.shipments`：`{id, at, qty, note}`；
- BOM 区新增「记录 N」按钮，可查看历史出货、撤销最近一次（库存自动加回，并写一条反向流水）；
- 计划板数只用于「需求核算」，输入框上已标注；计划小于已出不再报错，只把数字标红。

### 需求核算并入「芯片 / BOM」页

原来的独立「需求核算」页已删除，全部合到 BOM 页：

- 每块板的 BOM 表直接多出 **单板 / 本批需求 / 库存 / 缺口** 四列，改完计划板数立刻重算；
- 页面底部是 **全部芯片的需求汇总**，带「导出采购清单」；
- 需求 = 计划板数 × BOM 单板用量，再和当前库存比较，**不扣减历史出货**；
- 出完 100 块后计划照旧写 100，汇总仍然显示 200 的需求，不需要把上次的数量加上去。

### 缺料也能出货

以前库存不足会直接拦住整单。现在改成先算清楚、再由你决定：

| 选择 | 结果 |
|---|---|
| 取消 | 本次不出货，**所有库存原样不动** |
| 确定（强制出货） | 够的物料正常扣；不够的物料扣到 0，缺多少记进这次出货记录 |

弹出确认框会逐条列出：\`物料 A：需要 200，库存 150，缺 50\`。
出货记录里会标「缺料 N 种」，撤销最近一次时只加回**实际扣掉**的数量。

### 三处顺手的小改动

- **BOM 单板用量可以直接改**：表里「单板」那一格就是输入框，改完回车立即重算本批需求与缺口，不用再「删了重加」；
- **出货前就知道缺不缺**：输入板数时，弹窗里实时显示「库存充足」或「N 种物料不足 + 各缺多少」，点确定之前心里有数；
- **实验卡片快速更新**：卡片底部「快速更新」只填 状态 / 当前进展 / 下一步 / 日期 四项，「全部编辑」仍是原来的完整表单。ELFR 卡片的状态由分批记录推导，不在这里改；
- **「＋ 新增试验项」挪到卡片列表上方**，和「试验项与执行进展」标题同一行，不用再从页顶滚下去找。

### 实验设备登记（独立于资产台账）

实验要用的设备不一定是台账里的资产，可能是组里共用的、隔壁实验室借的、临时买的，所以**在实验卡片里单独记**，不引用资产编号：

- 每张卡片可登记若干设备：名称 / 状态 / 应还日期 / 备注；
- 状态三档：**待准备 → 实验中 → 已归还**；
- 应还日期**选填**，填了才会标逾期，不填就只当记录；
- 实验标记「已FT」但还有设备没归还 → 卡片红色提示，同时进「待执行事项」；
- 复制试验主题时，新卡片的设备重置为「待准备」，不继承上一轮的借还状态。

「资产设备」页保持原样，两边互不影响。

### 实验安排导出

- 「导出实验安排」现在**一次导出全部主题**（准备事项 + 投实验 + FT），文件名 `实验安排_全部主题_日期.xlsx`，用「实验主题」列区分；
- 不再给每张实验自动塞一行「实验概况」：有 ELFR 分批的实验只导出真实的投实验 / FT 工作项；没有分批的实验导出一条阶段安排（送样 / 实验 / 结项）；
- 总览页也加了「导出实验安排」入口，不用先切进某个主题。

### ELFR 排班：按「投实验 2、FT 1」均衡

- 工作量按**参与次数**算：一次投实验 = 2 个单位，一次 FT = 1 个单位（不再按颗数折算）。
  120 颗去 3 人、80 颗去 2 人，人均都是 40 颗，所以两种批次的一次参与算同样的工作量，不乘批次系数；
- 生成建议安排时，同等负载的人之间随机挑，**每次生成结果不同**，但每人总工作量之差不超过一次投实验；
- 手工改过的名字会被记住并锁定，点「⚖️ 重新平衡」只重排没锁定的名额；
- 平衡只在「草案批次」（待准备、无投实验日期、无 FT 记录）内进行，已开始/已完成的批次原样保留。

### 实验代码

- 实验项可填**代码版本**和**简要说明**（都选填）；
- 填了以后卡片上会显示一行「实验代码 v1.2.3 · 说明」；
- 两个字段可缺省，2.4 / 2.5 导出的 `data.json` 导入后自动补空串，旧数据不受影响。

### 待办把准备、送样、设备放在一条线上

- 「待执行事项」上移到「实验准备」面板**之前**，不用滚到下面才看见；
- 状态为「待准备」且有「送样时间」的卡片，自动按送样日期生成待办，不再依赖手填「下一步日期」；
- 设备未归还、设备逾期会生成「设备借还」类待办，实验做完也不会漏掉归还。

### 台账拖拽排序与分组折叠

- 「拖拽排序」进入平铺模式，拖动行即可调整顺序，退出后按新顺序展示，顺序会落盘；
- 「电容 / 电阻 / 保险丝 / 螺丝 / 散热片」分组行点击（或键盘 Enter / 空格）可折叠展开；
- 折叠状态存在 `localStorage` 的独立键里，不写进 `data.json`，不影响数据格式。

## 数据兼容

`data.json` 结构未破坏性变更，**V2.4 导出的备份可直接导入 V2.5**：

- 读：`boards.*.shipments` 缺失时自动补 `[]`，脏数据（非数组 / 混入 null）会被过滤；
- 写：在原有 `{qty, bom, shipped}` 基础上追加 `shipments`，旧版程序读到会忽略该字段；
- 导出头部的 `version` 变为 `2.5`，`material` / `test` 两部分结构与 V2.4 一致。

## 浏览器要求

- `DecompressionStream`（Excel 导入）与 CSS `:has()`：Chrome / Edge 105+；
- 通过 `file://` 打开时，浏览器的「自动加载 data.json」会被安全策略拦掉，请用「数据管理 → 选择 data.json」或直接拖入页面。
